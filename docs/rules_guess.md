## A. 推測

### A-1.【推測】「使用済み」と「ダウン」は同じ状態ではない
- 内容: エナの「使用済み」（ティザー⑥）と、ホロビト・ハートの「ダウン状態」
  （ティザー⑨）は、どちらも**横向き**で表現されるが、**別の概念**ではないか。
- 根拠:
  1. 公式が別々の語を一貫して使い分けている。
  2. **適用対象が一度も交差していない。** 「使用済み／未使用」の主語は常にエナ、
     「ダウン」の主語は常にホロビトとハートであり、
     「エナがダウンする」「ホロビトが使用済みになる」という表現は
     ティザー①〜⑫・入門①〜⑫のどこにも現れない。
  3. **復帰の契機が別々である。** 使用済みはエンドフェイズに未使用へ戻り
     （ティザー⑤⑥）、ダウンはオーバービートで解除される（入門⑫）。
     一方の復帰処理がもう一方に及ぶという記述はない。
  4. **同一の文の中で、対象ごとに異なる動詞が使われている。**
     妖狐 七尾（HB01-031）の能力欄:
     「自分の赤のエナを1枚選ぶ。**それを未使用にし**、**このホロビトを回復する**。」
     エナには「未使用にする」、ホロビトには「回復する」と書き分けられている。
     もし完全に同じ状態なら、1つの動詞で両方を処理できたはずである。
- ただし「両者は別ものである」と明示した記述もまだない。
  「横向きという1つの物理状態を、置かれている場所によって呼び分けているだけ」
  という可能性も、依然として否定できない。
- 想定される差の例: 「使用済みのエナを未使用に戻す」効果が、
  ダウン状態のホロビトを起こすことはない、という挙動。
  **HB01-031 はまさにその形をしている** —— エナを「未使用にし」、
  ホロビトを「回復する」を、別々の操作として並べて書いている。
- ただし「回復する」の定義は印字されていないため、
  それがダウン解除を指すのかどうかは `unknown`。
- 確信度: 高（上記4の書き分けにより、さらに上がった。ただし
  「別ものである」と明示した記述はまだなく、確定ではない）
- 確認方法: 公式ルールブックの用語集。
  「エナがダウンする」「ホロビトが使用済みになる」といった表現が出るかどうか。
- コードへの反映: **しない。**
- **設計上の決定（2026-08-28）**: この推測が未解決であるため、`simulator.html` は
  意味づけを持たず、卓上の物理事実である **「縦向き / 横向き」だけ** を保持する
  （`turned: bool`）。横向きであること自体はティザー⑥⑨で確定しており、
  未確定なのはその呼び分けだけだからである。
  UI では「横向き（エナ＝使用済み／ホロビト・ハート＝ダウン）」と併記するに留める。
  本推測が解決したら、そのときフィールドを分ければよい。
  分けたものを後から統合するより、後から分ける方が安全という判断。
- **追記（2026-08-28）**: 仮に本推測が正しく「動きは同じだが別もの」であったとしても、
  **フィールドを分ける必要はない**。上記2の観察のとおり適用対象が交差しないため、
  どちらであるかは **カードが置かれているゾーンから導ける**（エナゾーンなら使用済み、
  バトルライン／ハートゾーンなら ダウン）。
  むしろ `used` と `down` を別々に保持すると、
  `used=true` かつ `down=true` のような **本来あり得ない状態が表現可能になる**。
  したがって物理状態1つで保持する現在の設計は、本推測が正しい場合にも耐える。
- なお、ゾーンから呼称を導いて **UI に出し分ける** ことは技術的には容易だが、
  それ自体が本推測をコードに持ち込むことになるため行っていない。
  UI は両方の呼称を併記するに留める。

### A-2.【推測】自分と相手の同じ番号のラインが「正面」である
- 内容: 自分の第1ラインの正面は相手の第1ライン、第2は第2……ではないか。
- 根拠: 入門⑧「バトルラインは敵味方ともに5つあり」「内側のラインから、
  正面の敵との一騎打ち」。5つずつあり内側から順に解決する以上、
  同番号どうしが向かい合うと読むのが自然。
  ただし対応関係を明示した記述・図はまだない。
- 確信度: 高
- 確認方法: 公式ルールブックのバトルの項、対戦の図。
- コードへの反映: **しない。** シミュレーターは両陣地とも第1〜第5を
  同じ向きに並べるだけで、対応関係を示す作りにしない。

### A-3.【推測】色（属性）は「赤」以外にも複数ある
- 内容: ティザー⑪に「自分の**赤の**ホロビトが4体以上」とあり、
  色を限定する表現が使われている以上、他の色も存在するのではないか。
- 根拠: 限定表現の存在のみ。色の一覧は公開されていない。
  （ティザー⑧⑫の図に緑系・青系のカードが写っているが、
  イラストの配色とカードの色属性を同一視する根拠はない）
- 確信度: 中〜高（「複数ある」ことについて。何色かは完全に unknown）
- 確認方法: 公式サイトのカードリスト、色アイコンの説明。
- コードへの反映: **しない。** 確定しているのは「赤が存在する」ことだけ。

### A-4.【推測】左下の記号はレアリティ（C＝コモン、SR＝スーパーレア）
- 内容: ティザー①の2枚が `C`、ティザー⑪のレオジンが `SR`。
- 根拠: 2種類の値が確認でき、`SR` の方が明らかに強力なカードに付いていること。
  ただし項目名の印字はどこにもない。
- 確信度: 中〜高（前回より上がった。`SR` の確認により「単なる分類記号」より
  レアリティである可能性が高まった）
- 確認方法: レアリティ一覧の公開。
- コードへの反映: **しない。** `bottom_left_mark: "C" | "SR"` として保持する。

### A-6.【推測】オーバービートには「より高コスト」以外の条件もある
- 内容: 入門⑫でコスト条件（下になるホロビトより高コスト）は判明したが、
  加えて同ファミリーや特定カード指定などの条件もあるのではないか。
- 根拠: ティザー⑪の唯一の例が「雷獣 レオ」→「雷迅合身 レオジン」で
  どちらも「ライガ・ファミリー」であり、レオジンのフレーバーも
  「レオとジン、二人の心が重なり合った姿」と特定の組み合わせを示唆する。
  ただし **入門⑫はコスト以外の条件に一切触れていない**ため、
  無条件（コストさえ足りれば誰の上にでも）である可能性もある。
- 確信度: 低〜中（前回より下がった。入門⑫が条件を1つだけ挙げたため）
- 確認方法: 公式ルールブックのオーバービートの項、他のオーバー-Tカード。
- コードへの反映: **しない。** シミュレーターは重ねる組み合わせを制限しない。

### A-8.【推測】カード種別は「ホロビト」と「ワザ」の2つだけ
- 内容: 入門①のタイトルが「カードの種類」でありながら、
  挙げられているのはホロビトとワザの2つだけ。これが全種別ではないか。
- 根拠: 入門①「敵と戦う『ホロビト』とホロビトのパワーを上げる『ワザ』があるぞ！」。
  ただし入門①は連載の第1回であり、**説明を簡略化している可能性がある**。
  「〜がある」は網羅を宣言する表現ではない。
  なお「ブースト」は種別ではなくホロビトが持つ能力であることが確定している（§4）。
- 確信度: 中
- 確認方法: 公式のカードリスト、ルールブックのカード種別一覧。
- コードへの反映: **しない。** `rules_confirmed.md` §4 は
  「種別の全一覧は unknown」のままにする。

### A-9.【推測】「プレイシート」と「戦場」は指すものが違う
- 内容: 「プレイシート」は卓上に敷く物理的な製品（紙のシート／マット）の名称で、
  「戦場」はその上の遊技領域を指す呼称ではないか。
- 根拠: 一般的なTCGでの用法。公式にこの読み分けを示した記述はない。
  なお「プレイシート」と「プレイマット」は素材（紙かマットか）の違いであって、
  指す対象は同じ語である。
- 確信度: 中
- 確認方法: 公式ルールブック、製品構成の記載（プレイシートが同梱物として
  列挙されるかどうか）。
- コードへの反映: **しない。** `rules_confirmed.md` §5-0 は
  どちらが正式名称かを判定せずに2語を併記するに留める。

### A-10.【推測】ホロビトの左辺の `+2000` と赤丸「1」はブースト
- 内容: 壱合 レオジン（PR-001）の左辺に縦書きで `+2000`、その下に赤丸で `1`。
  これは入門⑪の言う「ブースト」の修整値とコストではないか。
- 根拠: 入門⑪「一部のホロビトは『ブースト』を持つ。ワザのように使えて、
  ホロビトのパワーを高められる」。ティザー①のワザカードは左辺に `+5000` を持ち、
  ティザー⑫でその値がパワーに加算されることが確定している。
  ホロビトカードに同種の `+N` が付いていることは、
  「ワザのように使える能力」の存在と整合する。
  赤丸の数値はコストと同じ意匠であることから、ブーストの使用コストと読める。
  さらに **一撃先戦！ 不死火&ショウ（HB01-063）でも同じ構造**（`+2000` と丸数字 `1`）を確認。
  丸の色はカード自身の色と一致している（PR-001 は赤、HB01-063 は緑）。
  **ただし「ブースト」という語はどちらのカードにも印字されていない。**
- 確信度: 高（2例目の確認により補強）
- 確認方法: 公式ルールブックのカードの見方、ブーストの説明。
- コードへの反映: **しない。** `rules_confirmed.md` §12 では
  項目名を `unknown` として値のみ記録する。

### A-11.【推測】壱合 レオジンのパワー `1114` は発売日にちなんだ数字
- 内容: 他のホロビト（4000 / 5000 / 7000）と桁も刻みも異なる `1114` は、
  発売日 11月14日に掛けた宣伝用の数値ではないか。
- 根拠: 同カードが発売告知を兼ねたプロモであり、
  「2026年11月14日 発売」を自ら印字していること。数字の一致。
- 確信度: 中
- 確認方法: 他のプロモカードのパワー値、公式のカードリスト。
- コードへの反映: **しない。** 誤記を疑って値を丸めたりせず、
  印字どおり `1114` を保持する（この推測は「1114 は誤記ではない」という
  記録として残す意味の方が大きい）。

### A-16.【推測】手札のカードは横向きにならない
- 内容: 「使用済み」も「ダウン」も場に出ているカードの状態であり、
  手札のカードが横向きになることはないのではないか。
- 根拠: 確認できた範囲で、手札のカードの向きに言及した記述が一切ない。
  エナは「使用済み」（ティザー⑥）、ホロビト・ハートは「ダウン」（ティザー⑨）で、
  いずれも場のカードについての記述である。
  ただし **「手札のカードは横向きにならない」と明示した記述もない。**
- 確信度: 高
- 確認方法: 公式ルールブック。
- **コードへの反映: している（例外）。** 依頼者の判断により、
  `simulator.html` は手札のカードのメニューに「横向きにする」を出さない。
  実際に触ってみて誤操作の原因になっていたため。
  なお既に横向きになっている手札のカードには「縦向きに戻す」を出す
  （直せなくなるのを避けるため）。移動やドラッグには一切制限をかけていない。
- **この項目は本ファイルの原則（推測をコードに入れない）の例外である。**
  ルールが判明して覆った場合は、この分岐を外すこと。

## A'. 判読できなかった読み取り（隔離）

イベント実物写真から「読めた気がする」だけの断片を隔離する場所。
**確定情報として扱わない。コードにもカードデータにも入れない。**
鮮明な画像が出た時点で照合し、一致すれば確定へ移し、外れていれば削除する。

**現在、隔離中の項目はない。**

### A'-1. 照合の記録（2026-08-28）

第1便の写真（グレアで判読困難）から確度「低」で読み取った5件について、
第2便の鮮明な写真で照合した結果:

| 読み取った文字列 | 結果 | 実際の印字 |
|---|---|---|
| このホロビトの下にあるカードの合計が3枚以上なら | **一致** | 自分の第1〜2ラインにいるホロビトの下にあるカードの合計が3枚以上なら |
| 自分の第1〜2ラインにいるホロビトが | **一致**（上と同一の文の一部だった） | 同上 |

| このワザは自分がこのバトルで他のワザを使っているときのみ使える | **一致** | 同左 |
| このワザを捨て、カードを3枚引く | **一致** | 同左 |

5件すべてが一致した。ただし**これは読み取りの精度が高いことの証明にはならない**。
第1便では他に多数の項目（カード名、ファミリー名、フレーバー、
カード番号、レアリティ記号）を「判読不能」として一切記録しておらず、
記録した5件はもともと読めた部分だけである。
**読めない箇所を書かなかったこと**が効いたのであって、
不鮮明な文字を当てられるという意味ではない。

## B. 未確定の論点（推測を立てずに保留）

確定情報が出るまで **推測すら立てない** と決めた論点。

### B-1. バトル
- パワーが同値のときの扱い
- 「一斉」に行われるバトルフェイズで、ワザ／ブーストの使用順や割り込みがどうなるか
- バトルに勝った側のホロビトに起きること
- ダウン状態がいつ解除されるか（あるいは解除されないか）
- 5つのラインすべてを順に解決するのか、決着で打ち切るのか

### B-2. ハート
- ハートの補充があるか
- ハートゾーンが空になった状態でさらにダメージを受けたときの処理
  （勝利条件の「最後のダメージ」が何を指すか）
- 手札に加わったハートのカードは通常のカードとして使えるのか

### B-3. エナ
- エナに置けるのが手札からのみか（初期の1枚は山札から）
- エナゾーンの上限枚数
- 山札が尽きたときのエナドローの扱い
- エナに置いたカードを他の用途で使えるか
- 支払いに使えるのが未使用のエナだけかどうか
- エナを置くのが召喚フェイズの中なのか、その前の独立した手順なのか
  （ティザー⑤と入門⑥で表現が異なる）

### B-4. オーバービート
- 束の下になったホロビトのパワーや能力の扱い（束として残ることは確定）
- 3枚以上重ねられるか
- コスト軽減後が0以下になる場合の扱い
- 重ねられたホロビトのパワーやトリガーがどう扱われるか
- 「より高コスト」が同コストを含むのかどうか

### B-5. ワザ／ブースト
- 1バトルで使える枚数の上限（2つ以上使えることは確定）
- 使用する正確なタイミング（バトルフェイズ中のどこか）
- **ワザゾーンの用途**（手札から使うことは確定したので、
  ワザゾーンが「使用中のワザを置く場所」なのか別の意味なのか）
- 使い終わったワザ／ブーストの行き先
- ブーストを「持つ」ホロビトが、それをどう使うのか（手札からか、場からか）
- ワザの「追加効果」にどんな種類があるか

### B-6. 召喚フェイズ
- 先手・後手が交互に行うのか、片方が全て終えてから交代するのか
- ホロビトをラインに出す枚数の上限
- 「内側の第1ラインから順に行う」が、空きラインを飛ばせない意味かどうか
  （第1が埋まっている場合に第3へ出せるのか）

### B-7. デッキ／手札
- 50枚が固定か上限か下限か
- 手札の上限枚数
- 山札が尽きたときの処理

### B-8. カード仕様
- 色の全一覧（赤・緑・青の3色を確認。他の色の有無）
- HB01-049 のファミリー名（カタカナ表記だが判読不能）
- HB01-034 の能力欄「コストは1大きくなる」が何のコストを指すか
- §13-12 のワザカードのカード番号・レアリティ記号・左辺の数値
- ファミリーの全一覧（ライガ・ファミリー / マボロシ・コミューン /
  スザク・ブラッド / タイジュ・ブラッド / ジャスティス・オーダー の5つを確認）
- ファミリーがルール上の意味を持つか、単なる所属表示か
- 「回復する」の定義
- 「青」という色名が能力文で使われるかどうか（現状はコスト丸の配色による判定のみ）
- レアリティ体系（`C` / `R` / `SR` / `DR` を確認）
- 同一カード番号に複数仕様がある範囲（HB01-097 以外にもあるか）
- 「バリア」の効果内容
- 「敗北時の効果」がキーワードか一般的な言い回しか
- キーワード能力の網羅的な一覧
- 同一キャラクターの複数カード間の関係（雷迅合身 レオジン / 壱合 レオジン）
- ホロビト／ワザ以外のカード種別の有無
- キーワード能力の一覧（「ダブルダメージ」以外）
- トリガーの全種類（全カードが必ず持つことは確定）
- トリガーがハート破壊以外の場面でも発動するか、発動が任意か強制か
- カード枠に存在する項目の完全な一覧

### B-9. 製品
- 発売日 2026-11-14 の一次情報での裏取り（現状は依頼者申告のみ）
- 販売形態、収録カード種類数

### B-10. シミュレーター設計上の保留
- ルール判定（フェイズ制御・コスト計算・バトル処理・勝敗判定）は実装しない。
- 「横向き」状態のデータ表現は、A-1 が未解決のため **物理状態1つ（縦/横）** で保持すると決めた
  （詳細は A-1 の「設計上の決定」）。A-1 が解決した時点で再検討する。
- カードデータ（実カード）を投入する段階で、TypeScript 化を再検討する。
  `unknown` を型で強制できるようになるが、現状はダミーカードのみで対象が存在しない。
